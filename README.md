# Mobile Sales Analysis Dashboard

This project focuses on analyzing mobile sales performance using Power BI visualizations and business intelligence techniques.

## Project Overview
The dashboard analyzes mobile sales data based on brand performance, regional sales, customer ratings, and product categories to generate business insights.

## Features
- Brand-wise sales analysis
- Region-wise performance tracking
- Customer rating analysis
- Best-selling category identification
- KPI-based dashboard visualization

## Tools & Technologies
- Power BI
- Microsoft Excel

## Objectives
- Analyze mobile sales trends and customer behavior
- Identify top-performing brands and categories
- Support business decision-making using data visualization

## Key Insights
- Identified high-performing mobile brands across regions
- Compared customer ratings with sales performance
- Highlighted profitable price segments and product categories
